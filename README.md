# 9. E-commerce-DB

Лабораторна робота з дисципліни «Сучасні технології баз даних»: база даних для електронної комерції з кількома магазинами (PostgreSQL) та консольний застосунок на C# з шаблонами Repository + Unit of Work.

Посилання на діаграму бази даних: https://dbdiagram.io/d/6ac4b5580f25a52d01a15c55

## Предметна область

Платформа об'єднує багатьох незалежних продавців. Кожен продавець має свій магазин, каталог товарів, залишки за розмірами та купони. Покупець додає товари з різних магазинів в один кошик і оформлює одне замовлення, яке розбивається на підзамовлення за магазинами. Ключові сутності підтримують м'яке видалення (soft delete), а також зберігають дату останньої зміни та користувача, який змінив дані.
